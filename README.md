# 🥭 Mango Quality Classification Using Deep Learning

An end-to-end Deep Learning project that classifies mango images into three categories: **Unripe, Ripe, and Rotten** using Convolutional Neural Networks (CNN) and MobileNetV2 Transfer Learning.

### Key Features
- Image dataset exploration and preprocessing
- Image resizing, normalization, and augmentation
- CNN model development from scratch
- MobileNetV2 transfer learning and fine-tuning
- Model evaluation using accuracy, precision, recall, F1-score, and confusion matrix
- Model comparison and selection
- Streamlit-based image classification interface

### Technologies Used
Python | TensorFlow | Keras | CNN | MobileNetV2 | NumPy | Pandas | Matplotlib | Seaborn | Streamlit

### Dataset
[Kaggle – Unripe, Ripe, Rotten Mango Dataset](https://www.kaggle.com/datasets/adrinbd/unripe-ripe-rotten-mango/data)

### Project Objective
To develop an image-based mango quality classification system that can automatically identify mango ripeness and spoilage stages using deep learning techniques.
